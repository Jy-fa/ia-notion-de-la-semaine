# IA : une notion par semaine

> **Je deviens une experte en LLM multilingues et agents IA.**

Ce dépôt est mon carnet de travail. Chaque semaine, je maîtrise une notion d'intelligence artificielle sous trois angles :

1. **L'actualité** : où en est la notion aujourd'hui (outils, papiers récents, débats)
2. **La compréhension profonde** : le papier fondateur, les mathématiques, le « pourquoi ça marche »
3. **L'implémentation** : d'abord *from scratch* en NumPy, puis avec un vrai outil

Chaque expérience suit la même démarche : question, hypothèse, montage, variable étudiée, mesures, conclusion.
